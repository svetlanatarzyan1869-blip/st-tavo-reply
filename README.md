# Tavo · Варианты ответа бота — расширение для SillyTavern

После того как **ты** (игрок) отправляешь сообщение, бот **не отвечает сам** — вместо этого под твоей
репликой появляется панель с вариантами того, как может ответить БОТ: карусель с типами
(Драма/Романтика/Спокойствие/Напряжение/Тайна/Неожиданное), цветами и бабочками, плюс карточка-загадка.
Ты выбираешь вариант — и он становится **первым (и единственным) ответом бота** на это сообщение.

Кнопки:
- **▶️ пусть бот так ответит** — пишет полноценный ответ бота в выбранном направлении;
- **🎲 Рискнуть** — неожиданный ответ, не показывая заранее;
- **🙈 подсмотреть** — короткий тизер;
- **🔄 другие варианты** — реролл.

Это пара к «Идеи для сюжета» с зеркальным триггером: та панель — под ответом бота (что дальше по сюжету),
эта — под сообщением игрока (как бот ответит). Панели не конфликтуют (разные namespace и место появления).

## Важно: бот перестаёт отвечать автоматически
Пока расширение включено, обычный авто-ответ бота на твоё сообщение **глушится** (через `stopGeneration`,
до запроса к модели — токены не тратятся). Ответ бота пишется только когда ты выбираешь вариант в панели.
Если захочешь вернуть обычный авто-ответ — выключи расширение, либо поставь `INTERCEPT_AUTO_REPLY = false`
вверху `index.js`. Глушится только обычная генерация (`type: normal`); свайпы, continue, regenerate и наши
собственные генерации работают как обычно.

## Как работает генерация
- **Варианты и тизер** — `generateRaw` (мета-задача вне чата).
- **Ответ бота** — `generateQuietPrompt` в «громком» режиме (полный контекст + пресет), результат
  дописывается как сообщение персонажа.

Панель **развёрнута** по умолчанию (её смысл — заменить ход бота, кнопка должна быть на виду).
Варианты сохраняются в `extra` сообщения — переживают перезаход.

## Установка (можно с телефона)
1. SillyTavern → Extensions (кубики) → **Install extension**
2. Вставь: `https://github.com/svetlanatarzyan1869-blip/st-tavo-reply`
3. Обнови страницу.

## Настройки (вверху `index.js`)
- `VARIANTS_COUNT` — сколько вариантов (по умолчанию 5)
- `SHOW_MYSTERY` — карточка-загадка (по умолчанию да)
- `CONTEXT_MESSAGES` — сколько последних сообщений уходит модели (по умолчанию 12)
- `INTERCEPT_AUTO_REPLY` — глушить авто-ответ бота (по умолчанию да)
